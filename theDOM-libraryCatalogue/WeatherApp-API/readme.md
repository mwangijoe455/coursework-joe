# Weather Alert App

## Description

This application retrieves active weather alerts from the US National Weather Service API using JavaScript Fetch API.

## Features

- Fetches weather alerts
- Displays alert headline
- Displays severity
- Displays affected area
- Displays alert description
- Handles invalid state codes
- Handles network errors

## Technologies

- HTML
- CSS
- JavaScript
- Fetch API

## API

https://api.weather.gov/alerts/active?area=CA

Replace CA with any US state code.

Examples:

CA
TX
NY
FL
WA

## Run

Open index.html using Live Server.
