#  React Simple Data Fetching – Random Dog Image

A React application that demonstrates **data fetching** with the `useEffect` hook. It loads a random dog image from an API when the page loads and lets users fetch a new image by clicking a button – with loading and error handling.

---

## Lab Requirements

-  Load a random dog image on component mount (`useEffect`).
-  Display a loading message while fetching.
-  Allow the user to fetch a new image via a button (`onClick`).
-  Handle errors gracefully.
-  Use no external libraries – only React and plain JavaScript.
