# Color Clock – Dynamic React Dashboard Widget

A colourful, responsive digital clock built with **React** and **Vite**, displaying the current date and time in a clear 24‑hour format. Includes a **dark/light theme toggle** and uses `date-fns` for elegant date formatting.

This project was created as part of a lab exercise to demonstrate:
- Setting up a React project with Vite  
- Using JSX to build UI components  
- Managing dependencies with `npm`  
- Incorporating external libraries (`date-fns`)  
- Applying modern CSS theming with custom properties  

---

##  Features

- **Live clock** – updates every second  
- **24‑hour time format** – `HH:mm:ss` (e.g., `14:35:22`)  
- **Formatted date** – e.g., `September 2nd, 2026`  
- **Day of the week** – full name (e.g., `Wednesday`)  
- **Dark / Light theme toggle** – persistent visual preference  
- **Responsive design** – works on mobile, tablet, and desktop  

---

## Tech Stack

- [React](https://reactjs.org/) – UI library  
- [Vite](https://vitejs.dev/) – build tool and dev server  
- [date-fns](https://date-fns.org/) – lightweight date formatting  
- CSS custom properties – for theming and maintainability
