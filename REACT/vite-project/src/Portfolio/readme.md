# Portfolio Platform SPA

## Project Description

This project is a Single Page Application (SPA) built with React. It provides a modern and responsive portfolio platform where projects can be displayed, searched, and added dynamically.

The application is designed for a creative agency or developer who wants to showcase previous work and easily add new projects.

## Features

* Responsive landing page
* Display a list of portfolio projects
* Search projects by name
* Add new projects dynamically
* Reusable React components
* React state management with `useState`
* Dynamic rendering using `.map()`
* Project filtering using `.filter()`
* Form handling using `onSubmit`




### App.jsx

The main component that manages the application state and combines all other components.

### ProjectCard.jsx

Displays individual portfolio projects.

### ProjectForm.jsx

Provides a form for adding new projects.

### SearchBar.jsx

Provides the search functionality for filtering projects.

### data.json

Contains the initial portfolio project data.

### App.css

Contains the responsive styling for the application.


## Responsive Design

The application uses CSS Grid, flexible layouts, and media queries to provide a responsive experience on desktop, tablet, and mobile devices.
